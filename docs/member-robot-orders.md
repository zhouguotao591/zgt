# 会员订单按机器人合并

会员订单列表、会员中心和每日盈利通知按机器人实际发送批次计单。同一会员在同一期使用多个机器人，各机器人分别计单；同一机器人不同发送批次也分别保留。

一个合并订单包含多个策略或下单类型明细，主订单展示合计金额、实际扣款、返还和净盈亏。任何明细尚未结算时，主订单仍为待结算。订单类型筛选命中明细后展示完整主订单。

底层策略明细、结算记录和资金流水保留，机器人金额计算及风控仍使用原始明细。历史记录有机器人信息时按机器人及期号归组；没有机器人和批次信息的历史记录保留原粒度，避免误合并。

验证：`python -m unittest discover -s tests -p test_member_robot_orders.py`，覆盖同机器人合并、多机器人隔离、会员权限、筛选分页、部分结算、持平、全额对冲及退款流水。日报回归使用 `test_daily_notices.py` 的 `DailyNoticeTests`。
