# 金额方案与独立策略信号

## 使用入口

1. 后台左侧「金额配置管理」新增方案，可选择固定、赢减亏加、亏后加额、亏后倍增。金额为整数 U，1—20000 U，可限制最低、最高金额及累计加减额次数。
2. 「机器人推送 → 账号与机器人 → 配置订阅与金额」，按策略选择「独立金额方案」及具体方案。一个机器人可以为不同策略选择不同方案，共用方案也独立记进度。
3. 机器人「配资风控」设置校准余额、固定余额止损、原配资/移动止损、单日亏损、最大回撤、单笔金额上限、连续盈亏暂停期数。
4. 策略管理和前台策略中心分别展示「独立实时信号 / 固定100U标准模拟」与「原模拟订单」。会员真实资金与订单仍在原会员账本中统计。

## 三层数据口径

- 信号：启用的策略按方向、观察窗口、阈值、排名、小时规则、轮次等条件持续判断。资金余额、连胜连亏暂停、加减额与执行止损不限制该信号。人工停用、开奖休息、时效、数据冲突、未核验数据与缺期仍有效。
- 标准模拟：每个合法实时信号固定100U，使用信号生成时的赔率快照结算。命中率=命中信号/已结算合法信号；退本仍计方向命中，利润按真实返本规则。未结算和失效信号不进入分母。
- 机器人实际执行：只有接收端确认执行且实际结算的会员订单推进金额。发送失败、未执行与过期不会推进。待执行确认或待结算时等待，不抢算下一笔，也不补发已跳过期。

实时信号从本次升级开始积累。历史补录、历史回测不冒充实时判断；停机期间不倒填预测。旧模拟账户数据保留原口径，不能与实时信号合并计算命中率。不同策略版本在账本中保留版本指纹和截止期快照。

## 金额规则

- 固定：每笔基础金额。
- 赢减亏加：赢后从上一笔金额扣减，亏后增加；退本不变。
- 亏后加额 / 倍增：亏后增加 / 乘倍数，赢后恢复基础。
- 累计加额与减额分别计数，相反结果不清零；任一达到配置上限后，下一笔恢复基础并清零两项。0为不限。调整额为0不累计；已到金额下限时发生非零减额操作仍累计。
- 金额先按整数U向上取整，再限制在方案的最低/最高金额内。机器人独立预算仍可拒绝执行。
- 状态粒度为订阅ID，即机器人×策略。换方案或切换金额模式重置该订阅状态；暂停/恢复订阅不会与其他订阅共用进度。
- 方案修改生成新版本，已有任务保存旧金额/旧版本。待上一笔确认完成后，新版本下一笔从基础开始。停用阻止新任务，已生成任务仍按冻结快照执行。
- 有效订阅使用中的方案不能删除；删除仅归档，历史版本和订单快照保留。

## 兼容与迁移

已有固定金额、模拟比例订阅保留，仍跟随原模拟订单，界面标为兼容。不会擅自改动正在执行的金额。管理员选择独立金额方案后才改为跟随独立信号；同订阅不会同时接收两条来源。

原策略的金额与风控字段收至「兼容模拟与历史回测参数」，继续用于原模拟账户和旧口径回测，不限制独立信号。旧回测收益不等同于新金额方案的机器人实际执行收益。

同一期同接收账号/机器人仍沿用既有合并发送、有效期、回调和幂等逻辑。消息保持“方向金额 方向金额”。人工停用策略仍阻止新推送，既有会员订单继续结算。

## 机器人预算

每日按北京时间结算日计算已实现盈亏。单日亏损和回撤预算包含未结算及预留敞口的潜在全损；上限为0时关闭该项。单笔上限按合并消息里的各笔订单检查。既有资金校准与配资保护保持有效。

连续盈利或亏损达到阈值时按目标开奖期号暂停指定期数，到期清零连续计数、重新检查全部预算。资金止损仍须人工核对恢复；恢复不能抬高实际校准资金。机器人暂停不会中断策略信号。

## 存储与运维

- 主库：strategy_signals、strategy_signal_versions、money_plans、money_plan_versions、money_plan_states；outbox冻结subscription_id、money_plan_snapshot。
- 独立持久运行库：data/strategy-signals-runtime.sqlite3。复用原算法方向引擎，以固定标准金额和无执行止损的独立状态运行，与实际账户隔离。启动恢复不会重复生成同策略同期信号；运行库换代有独立来源标识。
- 两个库都应纳入备份。运行库丢失会从当前期重新判断，不重建停机期预测。
- 独立信号异常记录到jobs的strategy_signals分类，不阻断原采集和旧模拟服务。
- 新后台金额管理具备独立页面/操作权限；主管理员默认可用，其他管理员需授权。机器人只可配置其有权管理会员的订阅。

## 验证范围

测试覆盖固定/递增金额、累计归零、下限、退本、冻结版本、方案停用/归档、未知执行阻塞、机器人订阅隔离、连续暂停恢复、旧订阅防重复、反转/走势/上期策略的独立信号、风险暂停后仍产出信号、持久重启去重。PC/H5浏览器验证新增方案、单位换算、机器人订阅与回显。
