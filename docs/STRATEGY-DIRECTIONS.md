# 策略方向与单边金额调整

所有新建、编辑保存和重新启用的策略，必须从大、小、单、双中选择一个开单方向。界面和策略保存/启用接口不再接受大小、单双合并方向。

各类型保留原入场条件：

- 反转：只对所选方向判断原有观察期数、差值和对侧连开条件。
- 小时：只有完整小时分析得出的少数方向与所选方向一致，才进入原来的跟随时段。
- 占优及内置走势：只有观察窗口占优方向与所选方向一致时下单；持平仍按原来的上一笔方向规则判断。
- 上期跟随：只有上期结果属于所选方向时下单。
- 单边：每期固定所选方向，仍受金额、余额、时效、休息维护及暂停限制。

旧的正在运行策略不自动猜选方向，保持原行为。列表会提示待选择方向；停用并等待未结算订单结束后，编辑选择具体方向再保存启用。旧订单、收益、本金、会员订阅及结算快照保留。

单边策略默认提供“赢后减额 / 亏后加额（按上一单）”金额调整方式，也可选固定金额、亏后加额、倍数递增：

- 盈利后，下一单从上一单实际金额减去设定金额；亏损后增加设定金额。
- 加额、减额各自累计，输赢交替不清零。任一累计次数达到上限时，下一单恢复基础金额，并同时清零两项计数。
- 累计上限0表示不限次数；调整金额0不累计该类次数；退本金保持金额和两项计数不变。
- 最低金额可选择玩法最低1U，或不低于基础金额。
- 该方式不使用另一套“连续亏损恢复基础”计数，避免与累计加额次数冲突。实时执行与历史回测使用同一金额调整函数。
- 原有策略已保存的固定、加额或倍数方式不会自动改成新方式。
