# 策略小时胜率

策略管理的每行新增“策略小时胜率”。弹窗默认选择以本地最新开奖为终点的最近30天，点击“开始分析”计算；可切换最近7天或自定义北京时间范围。单次读取20—100000期有效开奖。

使用提交时已保存的策略、赔率和维护过滤参数快照，复用独立回测进程。整段历史连续回放，跨小时不重置资金、轮次、加减额或风控。观察预热仅使用所选范围，起始状态为独立初始本金，不接续真实账户或范围外历史轮次。

按目标期开奖时间归入北京时间小时；支持逐小时与跨日期的24小时汇总。多类型逐笔统计，可按类型筛选；筛选只切换统计视图，不重新单独回放该类型。盈利胜率为盈利笔数除以全部已结算笔数，方向命中率单列；退本包含在分母。无下注显示空胜率，少于30笔标记样本较少（提示阈值，不代表统计显著性）。

点击小时查询对应下单明细，每页50笔。展示参数快照、缺期数、数据截止时间、主要未下单原因和收益指标；风险暂停可造成后续大量小时无下注。

相同快照、范围、有效开奖数据摘要与覆盖信息复用最近100次回测中的已完成结果；参数、赔率或开奖变化重新计算。仅点击入口才请求数据，不增加首页回测任务。沿用历史回测权限，不修改真实策略、会员订单、现金流水或常规月度回测汇总。

验证：`python -m unittest discover -s tests -p test_strategy_hourly.py`；原有 `test_history_backtest.py` 回归。浏览器验证最近30天连续回测、逐小时、24小时汇总及小时明细。
