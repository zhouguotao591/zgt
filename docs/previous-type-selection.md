# 上期跟随下单类型多选

上期跟随编辑器支持大小、单双、小单、大双、大单、小双、A/B/C球大小九种类型的单选或多选。算法跟随与算法排名入口沿用原单选配置。

多选仍保存在一条custom_strategies记录中，不拆分策略。各类型的下一笔金额、加减额次数、连胜暂停及胜负差值独立保存在state.type_states中；共用策略本金、日亏损和回撤风控。同一期可有多笔订单明细，明细共享策略ID，机器人只需订阅一次，按原规则合并为一条消息。

组合项仅在上一期恰好为对应组合时跟随，不匹配则等待并保持该类型金额状态。小单13、大双14退本不调整金额；三球大小保持1.99倍规则。机器人金额方案使用subscription_id＋previous_type独立计数，其他类型的待结订单不阻塞本类型；未标类型的历史待结订单仍保守拦截。

保存保持原ID、名字、余额及历史订单；已启用或存在未结订单时沿用原拒绝编辑规则。旧配置previous_types缺省None，继续原单类型执行；旧“组合”在编辑时预选四个组合，保存为同一策略的多类型选择。

订单及信号唯一约束升级为strategy＋target_draw＋direction，迁移保留所有列、订单ID、索引和触发器，重复运行不再重建。升级在SQLite事务中执行；拒绝存在外部外键引用的自动重建，上线前备份主数据库及独立信号运行库。

回测一次性预留同一期各类型投入后再结算，避免用第一类型尚未开奖的盈利资助第二类型。未下单期数按去重期号计算，跳过原因按类型统计；CSV包含previous_type。

测试：tests/test_previous_types.py、tests/test_previous_type_money_plans.py。
