# 扩展算法库及全历史回测

算法大厅内置 310 个确定性公式：大小、单双各 155 个。每类包括上期跟随、上期反转，以及观察期数为 5—55（含两端、逐个整数）的占优跟随、少数反转、转移跟随。

旧算法编号保持不变，不重复创建；每个类型的 153 个参数算法对应三种规则、51 个观察期数。转移跟随观察 N 次相邻转移，需要 N+1 个此前连续结果。次数持平时沿用上期结果。当前目标期和未来开奖不参与预测。

## 统计分离

- 窗口历史命中率：实时计算最近20、100、500、1000、2000、5000期的有效预测；缺期、未核验和观察窗口不足不计为命中或未中。
- 全历史自动回测：使用运行批次时本地全部已核验、非冲突、已开奖的历史记录。结果保存到 `algorithm_library_backtests`，页面标明截止期号，不会伪装成实时更新结果。
- 回测模拟收益：有效预测每期固定100U，按当前赔率与返本规则结算，不加减金额、不设本金耗尽停止。它是固定额历史分析，不代表可持续资金能力，也不计入模拟账户或会员账户。
- 实际下单收益：继续使用真实生成且已结算的实时模拟订单；不混入上述历史回测。

## 重算与导出

在项目目录执行：

```powershell
python -m pc28.algorithm_library --root D:/pc28
```

每个算法完成后保存结果。批次读取同一份已核验开奖快照，记录数据SHA-256及赔率。进度、JSON和CSV导出至 `data/exports/algorithm-library/`；CSV金额列以分为单位，列名包含 `_cents`。重新运行会更新各算法的全历史结果，不生成或推送订单。

前端支持全历史回测命中率排序、原有窗口排序、大小/单双分类及分页。排名自动跟随策略每类可选择第1—155名；实时排名仍使用所设最近期数，独立于固定截止时间的全历史回测。

大算法库的窗口统计使用前缀计数计算；详情按需生成逐期记录，避免为全部算法同时缓存大量明细。测试将加速算法逐期结果与原参考公式进行对照，覆盖5—55期全部规则、缺期、预热和收益结算。

## 浏览器回归

算法界面测试使用独立临时数据库和测试管理员，真实账户及推送配置不参与。先运行 `python tests/algorithm-ui-server.py --library-backtests`，再在另一终端运行 `node tests/expanded-library-browser.cjs`。每个浏览器脚本应使用全新的隔离服务；`tests/batch-strategy-risk-browser.cjs` 会在临时库中创建、停用和归档测试策略，验证跨页批量操作及资金校准。执行环境需安装Playwright与Chrome，脚本中的运行时路径按本机环境调整。
