机器人推送

根据新策略订单生成会员推送，实际金额由会员订阅配置独立决定。策略必须启用并由会员订阅；同一平台、同一期、同一会员账号的订单用空格合并，例如：单10 大10 小20。历史补单和回测不推送。

全局推送设置

此处账号和机器人仅作为新绑定的预填值，实际推送严格使用每位会员的绑定配置。账号和机器人 ID 须来自接收工具。信号类型须与接收规则一致；转发订单原文时，接收工具的消息模板应为 {text}，本站消息固定为方向+金额，同期用空格合并。

推送平台管理

每个平台独立配置接口地址和信号源密钥。远程工具须使用本服务器可访问的地址；127.0.0.1仅表示本机。停用平台后不再发送该平台订单。

会员订阅与推送绑定

由管理员配置会员订阅。每位会员绑定独立接收账号、机器人及信号类型；同一期按平台与会员分别合并；同一会员可在多个平台分别配置。必须添加会员绑定并配置实际金额后才会推送，未绑定不推送。策略启用且会员订阅开启后执行，无需额外推送开关。

合并发送记录

每行是一条合并消息，同一平台、同一期、同一会员账号只生成一个合并编号。接口已接收表示 HTTP 成功；重试沿用同一事件编号，接收端需按 event_id 去重。

已选 0 条

仅可删除已结束的发送记录；删除不影响订单、收益或推送去重。

会员推送绑定

会员实际金额独立于策略模拟金额；每个策略可选择固定金额或模拟订单比例；比例按每一笔模拟订单金额计算，向上取整到整数U；金额留空使用会员默认固定金额。同一平台内的接收账号和机器人不能重复绑定不同会员。接收工具消息模板应设为 {text}，账号和机器人须在接收工具中预先配置。修改后只推送新订单，不补发历史订单。

配置工具接口与独立信号源密钥
